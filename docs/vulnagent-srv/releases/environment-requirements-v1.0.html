VulnAgent 2.3.0 环境要求

服务器

  • Linux x86_64
  • 建议内存 ≥ 32GB
  • 建议可用磁盘 ≥ 100GB，数据目录使用持久化磁盘
  • Docker Engine 可用
  • Docker Compose v2（docker compose）或 legacy docker-compose

网络

  • 浏览器可访问 http://<服务器IP>:23000
  • 服务器可访问配置的模型服务 API Base URL
  • 离线安装不依赖互联网拉取代码或镜像

浏览器

建议使用最新版 Chrome、Edge 或 Firefox。

部署前检查

docker --version
docker compose version || docker-compose version
docker ps
free -h
df -h
