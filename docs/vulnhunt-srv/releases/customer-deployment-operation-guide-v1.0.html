VulnHunt 1.0.3 客户离线部署与基础操作手册

本文面向客户现场部署工程师。安装包为离线包，沿用一键 install.sh，安装后按本文完成 License 激活、管理员初始化、模型配置、创建扫描任务和查看结果。

1. 部署前准备

  • Linux x86_64
  • Docker Engine + Docker Compose v2，或 legacy docker-compose
  • 当前用户可执行 docker ps
  • 建议内存 ≥ 32GB，磁盘可用空间 ≥ 100GB
  • 可访问模型服务地址
docker --version
docker compose version || docker-compose version
docker ps
free -h
df -h

2. 校验并解压离线包

sha256sum -c vulnhunt-release-1.0.3.tar.gz.sha256
tar -xzf vulnhunt-release-1.0.3.tar.gz
cd vulnhunt-release-1.0.3

离线包内包含 Docker 镜像、部署脚本、VERSION.json、校验文件、Markdown/HTML 文档和截图。

3. 一键安装与健康检查

DATA_DIR=/opt/vulnhunt/data WEB_PORT=23000 ./install.sh
./doctor.sh

普通用户部署可使用：

DATA_DIR=$HOME/vulnhunt-data WEB_PORT=23000 ./install.sh

请备份整个 DATA_DIR，尤其是 $DATA_DIR/.secrets/vulnhunt-master.key。master key 丢失后，已保存的模型凭证无法解密。

健康检查通过后访问：

http://<服务器IP>:23000

4. 平台基础操作

4.1 License 激活

复制机器码，向供应商申请授权证书，粘贴 License 后点击“激活”。

4.2 初始化管理员 / 登录

首次激活后创建第一个管理员账号。后续访问使用管理员账号登录。

4.3 仪表板

登录成功后进入仪表板，可查看扫描数、漏洞统计、Token 用量和近期扫描。

4.4 模型凭证

进入“设置 → 模型凭证”，填写模型名称、API Base URL、模型 ID、API Key（自托管模型如允许可留空），保存后执行连接/运行时验证。

4.5 创建扫描任务

进入“任务 → 新建任务”。可上传源码包或填写 Git URL，选择模型凭证后点击“开始扫描”。

4.6 查看结果和报告

任务详情页包含 Overview、Findings、Reports、Workspace、POC 等标签页。任务完成后可查看漏洞结果和报告入口。

5. 升级、备份和排障

./upgrade.sh
./doctor.sh
./uninstall.sh

排障常用命令：

docker compose ps
docker compose logs -f service
docker compose logs -f web
验收清单：校验包通过、安装成功、doctor 通过、Web 可访问、License 激活、管理员登录、模型凭证可保存、可创建扫描任务、可查看结果和报告入口。
