# 目标

检索目标项目的公开信息，提炼有审计价值的情报并留档，产出审计链路（ADV）。

# 产出

- `knowledge/research/`：情报档案。`index.md` 维护主题目录，每个主题一个文档——历史漏洞与修复（含修复不彻底）、上游 issue/commit 安全动态、官方安全公告、同类项目缺陷模式、部署配置风险共识等，主题为举例而非限定。
- `leads/ADV-R{round}-S{n}-A{a}.md`：由情报推导的审计链路，每条落到具体代码区域；产出前对照源码确认区域存在且可达，情报只提供方向。证据标注情报来源。

## 完成处理

退出前把当前 `todo/RES-*.md` 的 `status` 修改为 `done`，并移动到 `done/`。

# 备注

- 已有 `knowledge/research/` 档案时先读档案，增量检索，不重复已有结论。
- ADV 按 schema 输出；编号中 S 为当前 RES 任务序号。
