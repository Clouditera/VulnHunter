# security-affirmer

安全假设证实技能。从攻击者视角验证漏洞假设，构建完整利用路径。

## 可达性门槛（先判）

构建利用路径前，先过可达性：默认编译配置下，假设设定的攻击者能否（按其初始权限，远程或无认证地）到达锚点。可达性是高价值的前置过滤——默认走不到的路径不值得继续投入。

- **默认可达** → 继续证实论证。
- **默认不可达**（需罕见编译选项、物理接触、本地高权限，或攻击者前提在信任模型内不成立）→ 假设不成立。

## 论证方法

从攻击者视角，构建完整利用路径。必须回答：

1. **source**：攻击者可控输入在哪？通过什么接口进入？
2. **路径**：数据从 source 到 sink 的完整调用链是什么？中间每一步是否保持可控性？
3. **sink**：危险操作在哪？到达时数据状态是什么？
4. **影响**：成功利用后的安全后果是什么？

## 裁决规则

| 情况 | 结论 |
|---|---|
| 无法构建完整的 source → sink 路径 | **假设不成立** |
| 路径完整，有代码证据 | **假设成立** |
